# 视频搜索系统使用说明

## 1. 软件简介

视频搜索系统是一款基于AI技术的视频内容搜索工具，能够根据图片或类别对视频进行智能搜索，帮助用户快速定位视频中感兴趣的内容。

主要功能特点：
- 支持图片搜索：上传图片，系统自动搜索视频中与图片内容相似的片段
- 支持类别搜索：选择预设类别，系统自动搜索视频中包含该类别的片段
- 智能评分：自动对搜索结果进行评分，按相似度排序
- 实时播放：支持直接播放搜索结果片段
- 用户积分系统：每日签到获取积分

## 2. 系统要求

- 操作系统：Windows 10/11
- CPU：Intel Core i5 或 AMD 同等性能处理器
- 内存：8GB 或以上
- 显卡：支持 CUDA 的 NVIDIA 显卡（推荐）
- 存储：至少 500MB 可用空间

## 3. 安装和启动

### 3.1 安装

1. 双击安装包，按照提示完成安装
2. 安装完成后，桌面会生成快捷方式

### 3.2 启动

1. 双击桌面快捷方式
2. 或从开始菜单找到"视频搜索系统"并点击启动
3. 启动后会显示登录窗口

## 4. 用户登录和注册

### 4.1 用户登录

1. 在登录窗口输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后进入主界面

### 4.2 用户注册

1. 在登录窗口点击"没有账号？点击注册"
2. 在注册窗口输入用户名、密码、确认密码和可选的邮箱
3. 点击"注册"按钮
4. 注册成功后自动返回登录窗口
5. 使用新注册的账号登录

## 5. 主界面介绍

### 5.1 标题栏

- 左侧：显示软件名称
- 中间：显示用户名和积分
- 右侧：显示签到按钮、语言选择和窗口控制按钮

### 5.2 左侧面板

- 搜索模式选择：图片搜索/类别搜索
- 视频选择：选择要搜索的视频文件
- 搜索条件设置：
  - 图片搜索：选择查询图片
  - 类别搜索：选择要搜索的类别
- 相似度阈值滑块：调整搜索结果的相似度阈值

### 5.3 中间面板

- 搜索结果显示：以卡片形式显示搜索结果
- 每个结果卡片包含：视频缩略图、时间戳、相似度评分
- 结果排序：支持按评分或时间排序

### 5.4 右侧面板

- 视频播放器：播放搜索结果片段
- 播放控制：播放/暂停、进度控制
- 日志信息：显示搜索过程和结果信息

## 6. 功能使用说明

### 6.1 视频搜索功能

#### 6.1.1 图片搜索

1. 选择搜索模式为"图片搜索"
2. 点击"选择视频"按钮，选择一个或多个要搜索的视频文件
3. 点击"选择图片"按钮，选择一张或多张查询图片
4. 调整相似度阈值滑块，设置合适的阈值（建议 85% 以上）
5. 点击"搜索"按钮开始搜索
6. 搜索结果会显示在中间面板，点击结果卡片可以在右侧播放器中播放

#### 6.1.2 类别搜索

1. 选择搜索模式为"类别搜索"
2. 点击"选择视频"按钮，选择一个或多个要搜索的视频文件
3. 在类别下拉框中选择要搜索的类别（如：person, car, dog等）
4. 调整相似度阈值滑块，设置合适的阈值（建议 85% 以上）
5. 点击"搜索"按钮开始搜索
6. 搜索结果会显示在中间面板，点击结果卡片可以在右侧播放器中播放

### 6.2 每日签到功能

1. 登录成功后，在标题栏可以看到"签到"按钮
2. 点击"签到"按钮
3. 签到成功后会显示签到成功提示
4. 签到获得的积分会自动添加到用户账户
5. 每日只能签到一次

## 7. 常见问题和解决方案

### 7.1 登录失败

- 确认用户名和密码是否正确
- 检查网络连接是否正常
- 确认用户服务是否正常运行

### 7.2 搜索无结果

- 调整相似度阈值，适当降低阈值
- 检查视频文件格式是否支持
- 检查查询图片是否清晰
- 确认选择的类别是否在视频中存在

### 7.3 播放失败

- 检查视频文件是否损坏
- 确认视频编码器是否支持
- 尝试重新选择视频文件

### 7.4 签到失败

- 检查网络连接是否正常
- 确认是否已经签到过
